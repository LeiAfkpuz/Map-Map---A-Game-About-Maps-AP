# Changelog

## 0.1.0 — first testing release

- 20 islands playable in any order in story mode; each island keeps its own progress, including partway through a
  mission set.
- Items: Island 2–20 unlocks, Shovel, Dividers, Camera, Build Tool, Telescope, Compass, Sextant, Glide, Stickers,
  Pencils, Ink Blot (filler).
- Checks: missions, 3-star ratings, buried treasures, Floor Is Lava challenges, landmarks (199 with all options on).
- Goals: Island 20 (Raven King's Treasure Cave), N islands completed, all 3-star ratings.
- In-game connection panel (server / slot / password), automatic reconnect, offline check queue.
- Separate save file per seed; the normal Map Map save is never touched while connected.
- "Sent / Received" messages; Archipelago picture on buried treasure.
